# 隐私

Keelhaven 生来就没什么可写进隐私政策的。

- **没有账号。** 不用注册，使用这个应用不需要任何身份。
- **没有遥测。** 应用不向外发送任何数据：没有统计分析，没有崩溃上报，没有使用记录。
- **没有我们的服务器。** 备份从你的 Mac 直达你选的目的地：本地硬盘、NAS，或你自己的 S3 兼容存储桶。中间没有任何 Keelhaven 的服务器。
- **上传前已加密。** 每一个字节离开 Mac 之前都已完成加密。仓库密码只存在 macOS 钥匙串里，不会被发往任何地方。

以上说的是应用本身，也就是碰你文件的那部分。另有三件事值得讲明白：

- **这个网站**是 GitHub Pages 托管的静态站点；和任何托管商一样，GitHub 能看到它处理的请求。网站用 Google Analytics 做基础访问统计，这是页面加载的唯一一个第三方，而且只在网站上，应用里没有。
- **下载按钮**会经过 `dl.keelhaven.app`，这是我们放在 Cloudflare 上的一个小 Worker：记下这次下载，再把你转到同一个文件。和任何托管商一样，Cloudflare 能看到这一次请求；我们从中只留下版本、所在国家、链接所在的页面或网站，以及发起请求的是浏览器、`curl` 还是爬虫，从不留下 IP 地址。
- **支持邮件**发到我们的地址后，经 Cloudflare Email Routing 转到我们自己看的邮箱。我们能看到你的地址和你写的内容，只用来回复你。

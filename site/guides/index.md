# Guides

Each one takes a destination from nothing to a first backup.

- [Back up a Mac to Backblaze B2](/guides/backblaze-b2) — the bucket, the key,
  and the one setting B2 needs. The same steps cover Amazon S3, Cloudflare R2,
  Wasabi and MinIO.
- [Back up a Mac to a NAS](/guides/nas) — Synology, QNAP or any server, as a
  mounted share or over SFTP.

Two more pages answer the questions that come before a guide:

- [Keelhaven for restic users](/restic) — exactly which commands it runs, and
  how to point it at a repository you already have.
- [Keelhaven and the alternatives](/compare) — Time Machine, Arq, Backblaze,
  Backrest and Vorta, and when each is the better choice.

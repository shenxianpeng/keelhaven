restic ​

Keelhaven's backups are performed by restic, an open source backup program. A copy of restic (version 0.19.1, universal binary) is included in the Keelhaven application bundle and redistributed with it, so you never have to install restic yourself.

Where to report problems ​

Report Keelhaven bugs to us, not to the restic project. A failed backup is far more likely to come from how Keelhaven drives restic than from restic itself, and its maintainers are volunteers. If a genuine restic bug does turn up, we report it upstream ourselves.
